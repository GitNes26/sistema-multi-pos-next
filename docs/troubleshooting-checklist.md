# Check-list de Troubleshooting

## 1. Diagnóstico preliminar

Antes de entrar código, haga:

1. Confirmar que el problema es recurrente o aislado.
2. Identificar los módulos afectados.
3. Revisar registro de errores.
4. Identificar variables relevantes.
5. Chequear existencia de soluciones conocidas.

---

## 2. Ruta de diagnostic 

1. Recolectar información:
   - scope
   - circunstancias
   - frecuencia
   - severidad

2. Reproducir problema en entorno controlado

3. Comparar sistema generativo / ambiente de producción

4. Identificar causa raíz:

```
posible causa -> hipótesis -> experimento -> resultados
```

5. Documentar causa raíz

---

## 3. Resolución y validación

1. Implementación de solución
2. Testeo de regresión
3. Validación con equipo
4. Cierre de incidente

---

## 4. Checklist operacional

- [ ] Log accedido
- [ ] Estado del sistema revisado
- [ ] Variables configuradas correctamente
- [ ] Pruebas ejecutadas
- [ ] Código validado
- [ ] Registros actualizados
- [ ] Notificación al equipo
- [ ] Cierre de incidente

---

## 5. Glosario

**Logs**: registro de eventos del sistema
**Stack**: ruta de ejecución del programa
**Servidor**: máquina con funciones en producción
**Recurrencia**: Error volviéndose a producir
**Causalidad**: Conector entre causa y efecto
