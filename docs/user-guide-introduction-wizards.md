# Manual del Supervisante — Introducción y Wizards de Sistema

## 1. Primer inicio y bienvenida

Al conectarse al sistema, el supervisante debe estar en su dispositivo según el contexto
(en campo, en control, en casa, etc.). El sistema reconoce la sesión y muestra la pantalla
de “iniciar supervisión”.

### Pasos principales al inicio

1. **Indicar el área/ubicación** al que estará supervisando.

   - Elija la sucursal, ubicación, o tramo de proceso.
   - Si el sistema lo detecta correctamente, le saldrá un mensaje de confirmación.

2. **Aceptar la condición de supervisión activa**.

   - Cuando inicia, el sistema le pide aceptar la supervisión.
   - Esto garantiza que está disponible para mostrarse.

3. **Verificar si la señal de supervisión aparece.**

   - El icono de “conexión” en la app/pantalla indica si está conectado.
   - Si no está conectado, el sistema recomienda revisar la conexión.

4. **Acceder a la pestaña principal** según el tipo de supervisión.

## 2. Wizards de configuración inicial

### Wizard 1: Crear ubicación / proceso supervivable

Este wizard es el primer paso para configurar supervisión.

**Paso 1: Seleccionar el tipo de proceso**

- Elija el proceso que desea supervisar.
- El sistema ofrece:
  - tramos de flujo,
  - equipos distribuidos,
  - sistemas de medida,
  - sistemas por ubicación.

**Paso 2: Seleccionar y añadir condiciones de supervisión**

- Elija las condiciones relevantes del proceso.
- El sistema trae las condiciones disponibles por ubicación.
- Elija lo que quiere ver para decidir.
- Si no hay condiciones suficientes, el sistema notifica por qué.

**Paso 3: Confirmar ubicación y supervisión**

- Confirme la ubicación.
- Verificar que la condición y el proceso estén en la app.
- Finalizar y guardar.

---

### Wizard 2: Supervisar una condición y condiciones de riesgo (cliente)

En este punto, el supervisante puede configurar condiciones de supervisión
dentro de un proceso supervisado.

**Paso 1: Mide**

- Elija la lectura o condiciones más importantes para su supervisor.
- Elija un sentido para priorizar (temperatura, presión, nivel, flujo, tiempo).

**Paso 2: Defina**

- Haga reglas de operación:
  - cuándo el supervisor recibe aviso
  - condition down rules

**Paso 3: Condición de decisión del supervisor**

- El sistema puede tomar condiciones de supervisor:
  - priorizar condición,
  - redundar condición,
  - segregar roles

**Paso 4: Vista de condición**

- Se selecciona vista del supervisor.
- El supervisor añade condiciones de campo para nivel control.
- El supervisor puede guardar.
- Es una red de condiciones del supervisor.

---

### Wizard 3: Agregar supervisor humano (ocasional)

En caso de que deba supervisar en campo también, puede agregar al supervisor
para que se le comunique y viajes afilados al/él.

**Paso 1: Involucrar persona**

- Elija modo de supervisión: correo/SMS/dispositivo.
- Agregue supervisor al equipo.

**Paso 2: Condiciones de supervisión de campo**

- Debe transmitir qué condiciones se van a notificar.
- Elegir una persona supervisada correcta.
- Indique un nivel de prioridad.

**Paso 3: Registrar recepción**

- Confirme que el supervisor o personas estarán informadas.
- Finalizar y guardar.
