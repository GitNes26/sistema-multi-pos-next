# Animaciones del estado del pedido

Reemplaza cada archivo por una animación Lottie JSON exportada desde After Effects con Bodymovin o LottieFiles. Conserva el nombre, lienzo recomendado 320×240, fondo transparente, bucle limpio, vectores y texto convertido a formas. Evita imágenes incrustadas y mantén cada archivo por debajo de 250 KB.

Estados: pending, confirmed, preparing, ready, in-transit, at-destination, delivered y cancelled.
